# Modelli di CU

Un documento per modello di CU (`kind: cu`). Descrive limiti e capacita': numero massimo
di MU, presenza del GPS, alimentazione, vincoli di airtime. Serve al server per validare
una configurazione e all'interfaccia per mostrare solo cio' che quel modello sa fare.

Primo documento previsto dal passo 19 della scaletta.
